# Описание проекта

я хочу написать инфраструктуру для анализа большого массива C кода 
Вот вывод команды cloc.

```text
Language                     files          blank        comment           code
-------------------------------------------------------------------------------
C                              180           6664           5530          37101
C/C++ Header                   414           5452           6904          23081
CMake                          101            632           1215           4303
Assembly                        21            453           1039           2025
```

нужно разработать набор инструментов на языке python, который составит базу sqlite в которой будет информация о файлах, об использовании заголовочных файлов, о том, где сущности языка СИ объявлены, где определены (файл, интервал позиций в файлах), какие комментарии есть перед / рядом с сущностью, какие глобальные, какие локальные, где используются (файл, позиция в файле / строка)

Эти данные будут использоваться в агентах для документирования, поэтому информация должна быть точной, из неё будет строиться контекст для агентов документирования.

Для примера есть дерево исходных файлов в sample/sel4.

## Инструменты

Какие инструменты нужно установить в систему для анализа. Спланируй. Добавь команды по установке в файл `./prepare.sh`

## Декомпозиция

Хорошо, если будет общий скрипт, прогоняющий полный цикл анализа: принимает дерево исходных текстов, опциональное имя файла базы данных (опционально - имя генерируется из имени каталога с файлами и текущей даты), выполняет все прочие скрипты и заносит данные в базу. Ведёт подробный лог всех операций, включая запуск внешних инструментов.

Дополнительные скрипты, такие как создание таблиц в базе данных, определение перечня файлов, определение сущностей и т.п., должны предоставлять API для общего скрипта, а так же возможность быть вызыванным из командной строки. Параметры (как минимум) - путь к каталогу с исходными файлами и путь к файлу базы данных sqlite.

Это нужно, чтобы можно было провести анализ вручную для верификации результатов.
